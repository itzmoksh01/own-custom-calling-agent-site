FAQ

Good to know.

Does the AI pretend to be me?

No. It always introduces itself as your AI assistant. That honesty is built in and can't be switched off — it's what keeps these calls legitimate.

Can it call any number?

Yes — pick a saved contact or type any number. You place the calls from your own telephony account.

What do I need to run it?

A Sarvam API key (voice, speech, LLM), a Twilio number, and this control panel connected to the backend. The panel is hosted here; the calling brain runs on a small server.

Is my data safe?

Transcripts and summaries are stored only where you run the backend, and emailed only to you. Keys live in your server's environment — never in this page.
